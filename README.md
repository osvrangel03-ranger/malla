# Malla

> La red social de tu ciudad. Local, con identidad real y sin algoritmo.

**Malla** —una red donde cada persona sostiene a las demás— es una red social pensada como
**herramienta, no como escaparate**. La ciudad es la unidad. No hay publicidad, no hay algoritmo que decida qué
importa, y no hay fantasmas: tu perfil dice de dónde eres.

El objetivo es recuperar el sentido original de estas plataformas: **conocer gente y
resolver cosas cercanas** —vender, comprar, enterarte de lo que pasa en tu colonia—
en vez de entrar a compararte con los demás.

## El problema

Las redes sociales dejaron de ser un medio de comunicación para volverse:

- Un concurso de comparación.
- Un sistema de discursos fabricados donde no distingues opinión real de contenido
  automatizado.
- Terreno de anonimato abusivo: perfiles fantasma, estafas y granjas de contenido.
- Un orden impuesto por un algoritmo que no sabe quién eres ni dónde vives.
- Un mercado poco confiable (marketplace lleno de estafas).

La causa no es solo de las empresas: **nos venden lo que elegimos comprar.** La respuesta
no es prohibir el algoritmo, sino **ofrecer algo mejor que el caos.**

## Principios

1. **Ciudad primero.** El contenido de tu ciudad es el corazón.
2. **Cronología, no algoritmo.** Nada está por encima de otra cosa por pago o engagement.
3. **Identidad real.** Verificación por teléfono + ciudad. Sin fantasmas.
4. **Cero publicidad.** Ningún anuncio, ningún contenido patrocinado disfrazado.
5. **Publicaciones personales.** Hechas por personas, no granjas automatizadas.
6. **Es una herramienta.** Si no sirve para resolver algo concreto, no es prioridad.
7. **Código abierto.** La transparencia es parte del producto.

## Estado del proyecto

**Fase 0 — Diseño y alcance.** Todavía **no hay código de la aplicación**. Este
repositorio por ahora contiene la visión, el alcance y la documentación de arranque.

El arranque se planea para **Tampico, Tamaulipas, México**, creciendo barrio por barrio.

## Qué **no** es esto (todavía)

- No es una app lista para instalar.
- No pretende reemplazar a WhatsApp ni competir contra su efecto de red global.
- No usa mallas Bluetooth como base (es una idea exploratoria de largo plazo).
