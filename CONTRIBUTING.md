# Cómo contribuir a Colonia

¡Gracias por querer ayudar! Este proyecto está en **Fase 0** (diseño), así que todavía no
hay código de la aplicación. Aun así, hay mucho por hacer.

## Formas de contribuir ahora mismo

- **Ideas y crítica:** abre un *Issue* con propuestas, riesgos o casos de uso para una
  red social local y de identidad real.
- **Diseño:** mockups, branding, accesibilidad.
- **Documentación:** claridad, ortografía, traducción (español/inglés).
- **Difusión local:** si vives en Tampico, tu perspectiva vale oro.

Cuando arranque la **Fase 1 (MVP)**, también buscamos código.

## Principios que respetamos (no negociables)

Antes de proponer algo, ten presentes los principios del proyecto:

1. Ciudad primero.
2. Cronología, no algoritmo.
3. Identidad real (teléfono + ciudad, sin documentos).
4. Cero publicidad.
5. Publicaciones personales, no granjas de contenido.
6. Es una herramienta, no un escaparate.
7. Código abierto.

Propuestas que contradigan estos principios (por ejemplo, añadir un feed algorítmico o
publicidad) se discutirán, pero de entrada van contra la esencia del proyecto.

## Privacidad y datos

Este proyecto maneja datos personales sensibles (ubicación, identidad). Toda
contribución debe respetar:

- Guardar **ciudad**, nunca coordenadas exactas.
- No recolectar datos que no sean estrictamente necesarios.
- Verificación por **teléfono + ciudad**, no por documentos oficiales.

Lee la sección de privacidad en [`docs/VISION-Y-ALCANCE.md`](docs/VISION-Y-ALCANCE.md).

## Flujo de trabajo

1. Abre un *Issue* antes de un cambio grande, para acordar el enfoque.
2. Haz un *fork* y trabaja en una rama con nombre claro (ej. `feature/feed-local`).
3. Mantén los *commits* pequeños y con mensajes claros.
4. Abre un *Pull Request* describiendo **qué** y **por qué**.

## Código de conducta

Sé respetuoso y constructivo. Este proyecto existe, precisamente, para recuperar la
comunicación sana. No se toleran acosos, discursos de odio ni ataques personales.
